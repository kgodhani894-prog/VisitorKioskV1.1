# MESWAO Acceptance Checklist

Mark each item only after direct observation on the tablet: Passed physically, Failed physically, Not yet tested, or Not testable in the current environment.

- [ ] Clean visitor start, details, and employee selection
- [ ] CameraX front camera opens in landscape; preview is natural, upright, and not stretched
- [ ] No flip/settings controls; capture produces exactly 2560x1920 JPEG
- [ ] Review is not mirrored; retake works
- [ ] Use Photo produces exactly one record and one email notification in a controlled test
- [ ] Confirmation, reset, back/cancel, Wi-Fi interruption, backend restart, and recovery
- [ ] Tablet reboot, Device Owner, true Lock Task, Home/Recents, notifications, Quick Settings, Settings, Gallery, and external-app blocking
- [ ] Administrator gesture, PIN lockout, recovery code, maintenance mode, relocking, and long-duration stability

Logs alone do not count as physical proof.
