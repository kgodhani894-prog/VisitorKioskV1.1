# Android tablet documentation

All guides for building, installing, operating, accepting, updating, and removing the kiosk tablet are collected here.

## Current guides

- `../README.md` — Android project overview, build instructions, first setup, and recovery behavior.
- `PROVISIONING_ANDROID14.md` — prepare a clean company-owned Android 14 tablet and assign Device Owner.
- `ACCEPTANCE_TEST_ANDROID14.md` — detailed physical checks and production acceptance gates.
- `MESWAO_ACCEPTANCE_CHECKLIST.md` — short checklist for recording the tablet acceptance run.
- `SECURITY_MODEL.md` — Android security boundaries and kiosk policy.
- `UPDATING_THE_KIOSK.md` — install an approved signed update.
- `DECOMMISSION_ANDROID14.md` — remove the tablet from service safely.

## Historical material

`../reference-artifacts/` contains test captures, old APK/source snapshots, rollback material, and optional inspection tools. It is not needed to build or run the current app. Do not install its archived APK as the current kiosk release.
