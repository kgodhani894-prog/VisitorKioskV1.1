# Internal project notes

These prompts support maintainer handoffs and project explanations. They are not instructions for installing or operating the company service and are not included in the release package.

- `HANDOFF_PROMPT.md` — context for continuing development and review.
- `PROJECT_EXPLANATION_PROMPT.md` — architecture and implementation briefing.

Canonical operator documentation stays in the parent `docs/` folder. Android-specific guides stay in `../development/android-kiosk/`.
