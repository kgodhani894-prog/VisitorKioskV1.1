# Project documentation

Use these documents for the active application and company operations:

- `DEBIAN_APACHE_DEPLOYMENT.md` — install and operate the Debian VM service behind Apache.
- `COMPANY_PILOT_RUNBOOK.md` — ordered company pilot and acceptance gates.
- `BACKUP_RESTORE_DRILL.md` — verify and restore a protected backup.
- `LOG_RETENTION_AND_RECOVERY.md` — understand logs and recovery behavior.
- `MICROSOFT_365_EMAIL_SETUP.md` — configure host notification email.
- `SECURITY_REQUIREMENTS.md` — deployment security requirements.

The Android tablet build, provisioning, and physical acceptance guides are grouped in `../development/android-kiosk/`. Historical deployment and audit material is in `archive/`; it is retained for context and is not current operating guidance. Internal handoff/explanation prompts are in `internal/` and are not included in the company release package.
